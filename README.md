# MX HQ

Kayden's motocross training, nutrition and lap-timing app.

- Hosted on GitHub Pages; data in Supabase (sign-in required, each user sees only their own data).
- Satellite imagery © Esri, Maxar, Earthstar Geographics. Location search © OpenStreetMap contributors (Nominatim).
- Polar sessions import through Polar AccessLink via Supabase Edge Functions.
- Edit files in `src/`, then run `./build.sh` to rebuild `index.html`.
